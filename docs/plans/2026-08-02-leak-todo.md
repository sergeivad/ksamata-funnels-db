## F78 — ТКМ / NR / ВК / Реклама

*В базе `num 74`, статус active (был draft до 2026-08-02).*

**Название воронки**
```
ТКМ / NR / ВК / Реклама
```

**Названия предложений регистрации**
```
Регистрация на ТКМ [ВК NR]
```

_Предложение найдено в реестре GetCourse с полным АВ-набором осей этой
воронки. Это единственное предложение с осями ТКМ + NR: платёжных предложений
под этой четвёркой в реестре пока нет вовсе — воронка только запускается._

**Метки заявок**
```
АВ Автоворонка
АВ Этап: Оплата
АВ Продукт: ТКМ
АВ Подрядчик: NR
АВ Канал: ВК
АВ Направление: Реклама
```

**Коды вебинарных комнат** — 10 штук, макс. день вебинара **5**

15:00 — `tkm1-15-nr`, `tkm2-15-nr`, `tkm3-15-nr`, `tkm4-15-nr`, `tkm5-15-nr`
19:00 — `tkm1-19-nr`, `tkm2-19-nr`, `tkm3-19-nr`, `tkm4-19-nr`, `tkm5-19-nr`

_Все десять проверены запросом к `web.ksamatacenter.com/room/<код>`: живые,_
_заголовки «1й…5й день онлайн-курса „КОД МОЛОДОСТИ ПОСЛЕ 50“» — по дням, без_
_пропусков. **Перенесены в базу 2026-08-02** (локально и на проде)._

**Название воронки**
```
ЖИВО-суставы-триал / NR / ВК / Реклама
```

**Названия предложений регистрации**

Регистрации нет по построению — это прямые продажи (маркер `АВ Прямые`).
Список названий регистрации в ЛИК оставить **пустым**: так живут десять
воронок ЛИК, включая ближайшую родню `f51` (та же четвёрка, подрядчик ИНХАУЗ)
и всю линейку ЖИВО.

В реестре GetCourse под этой четвёркой одно предложение, этапа «Оплата».

**Метки заявок**
```
АВ Прямые
АВ Этап: Оплата
АВ Продукт: ЖИВО-суставы-триал
АВ Подрядчик: NR
АВ Канал: ВК
АВ Направление: Реклама
```

**Коды вебинарных комнат** — нет

Вебинара у прямых продаж не бывает; в ЛИК `f51`, `f48` и вся линейка ЖИВО
заведены без комнат.
