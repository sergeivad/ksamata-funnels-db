## Общие настройки — одинаковы у всех 47 воронок ЛИК

Проставить каждой новой; отличаться тут не должно ничего.

| Поле | Значение |
|---|---|
| Шаблон | Вебинар на несколько дней |
| Часовой пояс | Europe/Moscow |
| Успешные статусы оплат | Получен, Списание с баланса |
| Исключаемые статусы оплат | Ожидается, Возвращен, Начислен на депозит |
| Исключаемые метки заявок | дубль, тест |
| Исключаемые метки заказов | дубль, тест |
| Метки, по которым считать только оплату | дубль |
| Исключаемые метки 1й оплаты | дубль, тест, 2-й платеж, 3-й платеж, полная оплата |
| Исключаемые метки выручки | дубль, тест |
| «Бесплатный» у заявок | Нет |
| «Бесплатный» у регистрации | Да |

Единственная воронка ЛИК, где это не так, — `f21`: у неё вместо списка
исключаемых статусов лежит старый формат `exclusion_types`. Это её дефект,
повторять не надо.
