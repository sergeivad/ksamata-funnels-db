# Архив одноразовых скриптов

Скрипты, которые уже отработали на живой базе и больше не запускаются.
Лежат здесь как летопись: по ним видно, откуда взялись те или иные данные
(коды ЛИК, лендинги, статусы, переносы воронок на прод).

**Каталог исключён из `tsc`** (`tsconfig.json` → `exclude`). Причина: скрипт
пишется под доменную модель того дня, когда его применяли. Поддерживать
пятнадцать отработавших файлов в согласии с сегодняшними типами дороже, чем
польза от этого — а изменить их задним числом значит соврать о том, что было
сделано на самом деле.

Сюда переехали скрипты, обращавшиеся к `funnels.landing_url`: после Phase-10
адрес лендинга живёт только в блоке «Лендинги», поля больше нет ни в API, ни в
доменных типах (см. CLAUDE.md, раздел про Phase-10).

**Запускать отсюда ничего не нужно.** Если понадобится похожая разовая правка —
пишите новый скрипт в `scripts/` под текущую модель, а после применения
переносите его сюда.
